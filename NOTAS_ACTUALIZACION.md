# Cómo probar la versión V6.3

1. Descomprimir el paquete completo en una carpeta independiente de la versión que está publicada.
2. Probar mediante GitHub Pages en una rama o repositorio de pruebas; mantener la versión pública sin alterar.
3. Conectar a Internet para que se carguen Leaflet y el mapa base OpenStreetMap.
4. Seguir los seis controles interactivos de `INFORME_FASE_2B.md`.
5. Reportar cualquier discrepancia con captura y nombre del barrio o capa.

No mezclar archivos sueltos de V6.1 y V6.3: la prueba requiere que `index.html`, `assets/` y `data/` correspondan al mismo paquete.
